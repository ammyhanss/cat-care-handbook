This group holds hormone diseases. [Hyperthyroidism](./hyperthyroidism/) and [diabetes mellitus](./diabetes/) are literature-checked. A veterinarian has not reviewed them. They cannot be used to choose a drug.

Weight loss, a rising appetite, more drinking, and more urine need blood tests. The same changes occur in other diseases. If the cat stops eating, vomits, is weak, or breathes with effort, use [See a vet now](../../urgent/). This site does not give insulin or antithyroid doses.
